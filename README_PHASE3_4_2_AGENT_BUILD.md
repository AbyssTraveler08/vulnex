
## Phase 5 dashboard/report update

The dashboard now provides a **Full Device Report** for endpoints with an authorized Vulnex Agent profile. The generated PDF combines endpoint inventory (hardware, OS/identity, network interfaces, installed software, services and users) with the network assessment (open TCP ports, Nmap NSE findings, CVE findings and remediation guidance) when an assessment is available.

The dashboard also includes a visual refresh with a security-focused hero header, metric cards and cleaner section/tab styling. Existing discovery, endpoint agent, Nmap and vulnerability workflows remain unchanged.
