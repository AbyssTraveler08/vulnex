# Vulnex 🔍

Vulnex is a vulnerability scanning and reporting tool built with Python and Streamlit.

## Features

- Automated Nmap scanning
- Vulnerability detection
- Risk visualization charts
- PDF security reports
- Interactive web interface

## Technologies Used

- Python
- Streamlit
- Nmap
- Matplotlib
- ReportLab

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/vulnex.git
cd vulnex
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
